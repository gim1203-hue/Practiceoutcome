Steps to create a new repository and link it to local project

Terminal commands for VSCode for adding new repository

  1. After creating a new folder and a file in (index.html)
  2. Press (shift+1 enter). make sure to save file in vscodes.
  3. then go to github and create a new repository and
  4. copy the url of the repository and paste it in the second command in the terminal of vscode.
  5. git init
  6. git remote add origin
  7. git add .
  8. git commit -m "initial commit"
  9. git push -u origin master
-------(to update latest changes)-------
  1. git add .
  2. git commit -m "update my html file"
  3. git push
----------------------------------------------------------

To clone resository from GitHub to local machine

  1. copy url from github (control+c)
  2. open new window in vscodes
  3. press (control+shift+p)
  4. write (Git: Clone)
  5. paste url (control+v) press enter
  6. select folder where you want to save the project

OR

  1. copy url of repository from github (control+c)
  2. open a new folder in VScode
  3. type git clone then press (control+v) to paste url in the terminal.

--------Create Branch on VSCode----------

  1. git checkout -b newbranchname
  2. git add .
  3. git commit -m "branchname"
  4. git push -u origin new branch name

--------Delete a Branch in Terminal----------

Note: you can't delete the branch you are currently on.

  1. git branch -d branchname

------creating and moving branches in git------

(type command clear in terminal to clear the terminal)

  1. git branch
  2. git checkout
  3. git push origin (name of branch)
  4. git add .
  5. git commit -m "add (file name)"
  6. git push -u origin (file name)

------------Merge branches to the maste---------r

  1. git branch (to see which branch is active)
  2. git checkout branch name (to select which branch to merge to)
  3. git merge branch name (which branch you want merged)
  4. git push

------------To merge branch using rebase------------

  1. git branch (to see which branch is active)
  2. git checkout branch name (to select which branch to merge to)
  3. git rebase branch name (which branch you want merged)
  4. git push

-------(to delete a branch)-------

  1. git branch -d (to delete a branch locally)
  2. git push origin --delete (to delete a branch from github)
  3. git push origin (to push the branch to github)
  4. git checkout -b (to create and move to new branch)
  5. git merge (to merge the branch to main branch)

-------Compare Branches to See the Difference----------

  1. git diff branch1..branch2

----(Git fetch)---------------------

  1. *after creating a file and new branch in git hub*
  2. *open visual studio code*
  3. git fetch origin (to fetch data from github)
----------------------------------------------------

------------(Git pull)------------

  1. * combination of fetch and merging*

  3. git checkout branch name
  4. git merge branch name main/master
  5. git push

-----------Git Push------------

  1. git push origin (to push the branch to github)

-------Creating Pull Request----------

  1. open secondary branch add content
  2. push to git hub and open github
  3. create a pull request from secondary to main branch on git hub to review changes and viewer input. verify change.
  4. confirm and merge
  5. open vscode pull changes for github.

------How to Perform Stash and List/Save and Apply Stash---

  1. git stash save "added paragraph"
  2. git stash save "content in file name"
  3. git stash list
  4. git stash apply
  5. git stash save again
  6. git stash apply

--------Withdraw Staged Changes----------

  1. git status
  2. git add . (staged)green
  3. git status
  4. git reset. (unstaged)red
  5. git status
  6. git add . (staged)green
  7. git reset file name (to reset only 1 file)

--------How to Revert Commit----------

  1. add commit push to git hub
  2. select commit copy hash
  3. git revert (past hash) on vscode
  4. open new window make commit then
  5. git push to git hub.

--------Tagging----------

  1. git tag -a <tag-name> -m "tagging message" <commit_hash>
  2. git tag (for name)
  3. git tag -n (for message of tag)
  4. git push origin <tag name>

--------Resetting a File----------

  1. git reset file.txt
