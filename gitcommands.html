Here is a larger Git command quick reference list covering the major Git commands used by software engineers. (Git has many internal commands, but these are the important ones developers encounter.) Git Command Quick Reference Git Setup & Configuration * git --version — Check Git version. * git config — Configure Git settings. * git config --list — Show all settings. * git config --global user.name "Name" — Set username. * git config --global user.email "email" — Set email. * git help — Open Git help. * git help — Get help for a command. ⸻ Create & Copy Repositories * git init — Create a new repository. * git clone — Copy a repository. * git clone --branch — Clone a specific branch. ⸻ Check Repository Information * git status — Show current changes. * git diff — Show unstaged changes. * git diff --staged — Show staged changes. * git log — Show commit history. * git log --oneline — Short commit history. * git log --graph — Show branch history. * git show — Show commit details. * git blame — Show who changed each line. * git reflog — Show previous Git actions. ⸻ Add & Save Changes * git add . — Add all changes. * git add — Add one file. * git add -A — Add all changes including deletions. * git commit -m "message" — Save changes. * git commit -am "message" — Add and commit tracked files. * git commit --amend — Modify last commit. ⸻ Upload & Download Changes * git remote -v — Show remote connection. * git remote add origin — Connect GitHub repository. * git remote remove origin — Remove remote. * git fetch — Download updates only. * git pull — Download and merge updates. * git push — Upload changes. * git push origin — Push a branch. * git push -u origin — Push and remember branch. * git push --force — Force upload changes. * git push --tags — Upload tags. ⸻ Branch Commands * git branch — List branches. * git branch — Create branch. * git branch -a — Show all branches. * git branch -d — Delete branch. * git branch -D — Force delete branch. * git switch — Change branch. * git switch -c — Create and switch branch. * git checkout — Switch branch (older method). * git checkout -b — Create branch (older method). ⸻ Merge & Combine Code * git merge — Combine branches. * git rebase — Move commits onto another branch. * git cherry-pick — Copy a specific commit. * git merge --abort — Cancel merge. * git rebase --abort — Cancel rebase. ⸻ Undo & Fix Mistakes * git restore — Undo file changes. * git restore --staged — Remove from staging. * git reset — Move HEAD pointer. * git reset --soft HEAD~1 — Undo commit but keep files. * git reset --mixed HEAD~1 — Undo commit and unstage. * git reset --hard HEAD — Delete local changes. * git revert — Safely undo commit. ⸻ Stash (Temporary Save) * git stash — Temporarily save work. * git stash list — Show saved stashes. * git stash pop — Restore saved work. * git stash apply — Apply stash. * git stash drop — Delete stash. * git stash clear — Delete all stashes. ⸻ File Management * git rm — Remove file. * git mv — Rename/move file. * git clean -fd — Remove untracked files. ⸻ Tags & Releases * git tag — List tags. * git tag — Create a tag. * git tag -a -m "message" — Create release tag. * git push --tags — Upload tags. * git describe — Show version information. ⸻ Searching & Debugging * git grep — Search code. * git bisect start — Start bug search. * git bisect good — Mark working version. * git bisect bad — Mark broken version. * git bisect reset — Finish debugging search. ⸻ Submodules * git submodule add — Add another repository. * git submodule update — Update submodules. * git submodule init — Initialize submodules. ⸻ Advanced Repository Commands * git archive — Create project archive. * git bundle — Package repository. * git worktree add — Create another working folder. * git worktree list — List worktrees. * git worktree remove — Remove worktree. * git gc — Clean repository. * git fsck — Check repository errors. * git prune — Remove unused objects. * git rerere — Remember conflict resolutions. * git notes — Add notes to commits. * git replace — Replace Git objects. ⸻ Patch Commands * git diff > file.patch — Create patch file. * git apply file.patch — Apply patch. * git format-patch — Create email patches. * git am — Apply email patches. ⸻ Everyday Software Engineer Workflow Most days you will use: 1. git pull 2. git status 3. git add . 4. git commit -m "message" 5. git push 6. git branch 7. git switch -c feature-name 8. git merge 9. git diff 10. git log --oneline Visual Studio Code, GitHub, and team projects.
